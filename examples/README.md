# Synthetic examples

These original, fictional examples contain no LoCoMo or LongMemEval records.

- `observations.json`: input for `python -m jev_mem --mode build`.
- `locomo_synthetic.json`: one small sample in the LoCoMo loader's format.

They demonstrate schemas, not benchmark quality. Running either through the
live pipeline uses paid providers. Use `python -m jev_mem.demo` for a fully
offline demonstration with mocked decisions and embeddings.
